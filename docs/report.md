# Results

Generated by `scripts/report.py` from the records in `tests/baselines/` and `tests/mir/wins/`. Device: AMD Instinct MI355X (gfx950), ROCm 7.14.60850. Baseline: `amdclang -O3` on the HIP version of each kernel. Protocol `agc-timing-amd-2`: both code objects alternate in one process, the statistic is the median of the paired ratio with a 95 % bootstrap interval, and a result is a win only when the whole interval is above 1.01. Every agc result passed the full battery (hidden seeds, shape variants) before it was timed.

## GEMM against hipBLASLt

C[M,N] = A[M,K] @ B[N,K]^T, bf16 inputs, f32 result. amdclang emits no MFMA for the HIP kernel, so the meaningful comparison is the library.

| Shape | amdclang ms | agc ms | hipBLASLt ms | agc vs amdclang | agc time / hipBLASLt time | agc TFLOPS |
|---|---|---|---|---|---|---|
| 4096 x 4096 x 4096 | 119.48 | 0.2868 | 0.1083 | 418x | 2.65 | 479 |
| 2048 x 8192 x 4096 | 119.37 | 0.2892 | 0.1125 | 414x | 2.57 | 475 |
| 8192 x 2048 x 4096 | 119.77 | 0.2896 | 0.1065 | 412x | 2.72 | 474 |
| 2048 x 2048 x 2048 | 14.99 | 0.0737 | 0.0293 | 203x | 2.52 | 233 |

agc takes 2.5x to 2.7x hipBLASLt's time. The kernel is bound by operand-load throughput (7 to 8 TB/s in every variant); the next factor needs operands shared between waves through LDS (issue #23). The roadmap's target of 1.5x was not met.

## Reproduce

```
make test                       # CPU tests, then GPU tests through the executor
make baseline                   # amdclang baselines
.venv/bin/python scripts/policy.py     # the default policy on every manifest
.venv/bin/python scripts/generated.py  # every generated variant
.venv/bin/python scripts/gemm.py       # GEMM against amdclang and hipBLASLt
.venv/bin/python scripts/report.py     # this file
```
