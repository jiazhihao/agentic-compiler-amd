# Results

Generated by `scripts/report.py` from the records in `tests/baselines/` and `tests/mir/wins/`. Device: AMD Instinct MI355X (gfx950), ROCm 7.14.60850. Baseline: `amdclang -O3` on the HIP version of each kernel. Protocol `agc-timing-amd-1`: both code objects alternate in one process, the statistic is the median of the paired ratio with a 95 % bootstrap interval, and a result is a win only when the whole interval is above 1.01. Every agc result passed the full battery (hidden seeds, shape variants) before it was timed.

## GEMM against hipBLASLt

C[M,N] = A[M,K] @ B[N,K]^T, bf16 inputs, f32 result. amdclang emits no MFMA for the HIP kernel, so the meaningful comparison is the library.

| Shape | amdclang ms | agc ms | hipBLASLt ms | agc vs amdclang | agc time / hipBLASLt time | agc TFLOPS |
|---|---|---|---|---|---|---|
| 4096 x 4096 x 4096 | 119.72 | 0.3064 | 0.1107 | 391x | 2.77 | 448 |
| 2048 x 8192 x 4096 | 119.58 | 0.3140 | 0.1096 | 381x | 2.86 | 438 |
| 8192 x 2048 x 4096 | 119.65 | 0.3171 | 0.1068 | 378x | 2.97 | 434 |
| 2048 x 2048 x 2048 | 14.99 | 0.0928 | 0.0290 | 161x | 3.20 | 185 |

agc is 2.8x to 3.2x slower than hipBLASLt. The kernel is bound by operand-load throughput (7 to 8 TB/s in every variant); the next factor needs operands shared between waves through LDS (issue #23). The roadmap's target of 1.5x was not met.

## What did not work

| Attempt | Result |

| `axpy`: elementwise(elements_per_lane=1) | loss, 0.975 (0.966 to 0.979) |
| `cast_bf16`: elementwise(elements_per_lane=1) | loss, 0.968 (0.964 to 0.972) |

| `gemm_bf16`: unroll_loads(factor=8) | parity, 0.999 (0.998 to 0.999) |
| `gemm_bf16`: unroll_loads(factor=16) | loss, 0.971 (0.970 to 0.971) |
| `axpy`: all arguments in one scalar load (agent edit) | parity, 0.9995 (0.993 to 1.004) |
| `matvec`: first unroll attempt with `v[5:8]` (agent edit) | rejected by the static check (tuple alignment) |
| `transpose`, `gemm_tiled` | no candidate: no counted load loop, no template; amdclang's build is shipped |
| MFMA GEMM within 1.5x of hipBLASLt | not reached (2.8x) |

## Reproduce

```
make test                       # CPU tests, then GPU tests through the executor
make baseline                   # amdclang baselines
.venv/bin/python scripts/policy.py     # the default policy on every manifest
.venv/bin/python scripts/generated.py  # every generated variant
.venv/bin/python scripts/gemm.py       # GEMM against amdclang and hipBLASLt
.venv/bin/python scripts/report.py     # this file
```
