# agentic-compiler-amd

Python-first agentic compiler for tensor-algebra kernels on AMD MI355X (`gfx950`, wave64),
emitting CDNA4 assembly directly. Design: `docs/design.md`. Roadmap: `docs/roadmap.md`
(GitHub issue #1). `~/agentic-compiler` is the NVIDIA reference implementation: read it
for design and infrastructure, never commit to it.

## Working in this repo

- **Before any development work, load the `dev-workflow` skill**
  (`.claude/skills/dev-workflow/SKILL.md`) and follow it: issue per task, branch + PR.
- `docs/progress.md` is the progress log: append an entry when a task is done (what was
  built, measured numbers, what is open).
- Python env: `.venv` (`.venv/bin/python`, `.venv/bin/pytest`). ROCm at `/opt/rocm`,
  LLVM tools at `/opt/rocm/llvm/bin`.
- Tests: `make test` (CPU tests + GPU tests, which run through the executor).
  `make test-cpu` is the GPU-free subset (what CI runs).
- Everything that touches the GPU goes through `agc.runtime.executor.run_job`
  (machine-wide lock, subprocess isolation). Do not launch kernels from the session process.
- No architecture constants in Python: they live in `agc/arch/gfx950.yaml`.
- The ISA table `agc/isa/cdna4.json.gz` is generated by `scripts/gen_isa.py` from AMD's
  `amdgpu_isa_cdna4.xml`; do not edit it by hand.
